# rjd3revisions: Revision analysis with 'JDemetra+ 3.x'

Revision analysis tool part of 'JDemetra+ 3.x'
(<https://github.com/jdemetra>) time series analysis software. It
performs a battery of tests on revisions and submit a report with the
results. The various tests enable the users to detect potential bias and
sources of inefficiency in preliminary estimates.
